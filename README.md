# 🌐 Language Translation Tool

A simple and interactive **Language Translation Tool** built with Python and Streamlit, developed as part of my **Artificial Intelligence Internship at [CodeAlpha](https://www.codealpha.tech/)**.

This tool allows users to enter text, select a source and target language, and get an instant translation — with added **copy-to-clipboard** and **text-to-speech** features.

---

## 📌 Features

- ✅ User-friendly web interface (built with Streamlit)
- ✅ Select source & target language from a dropdown
- ✅ Auto-detect source language option
- ✅ Translation powered by Google Translate (via `deep-translator`)
- ✅ Copy translated text with a single click
- ✅ Listen to the translated text using Text-to-Speech (`gTTS`)

---

## 🛠️ Tech Stack

- **Python 3**
- **Streamlit** – for the web interface
- **deep-translator** – for translation
- **gTTS (Google Text-to-Speech)** – for audio output

## ⚙️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/CodeAlpha_LanguageTranslator.git
   cd CodeAlpha_LanguageTranslator
   ```

2. **Install the required libraries**
   ```bash
   pip install streamlit deep-translator gtts
   ```

3. **Run the app**
   ```bash
   streamlit run app.py
   ```

4. The app will open automatically in your browser 🎉
